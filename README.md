# 🚗 Car Rental Management Dashboard

## Project Overview

Car Rental Management Dashboard is a modern web application designed to help a single car rental agency efficiently manage its daily operations.

The system centralizes vehicle management, customer records, rental operations, contracts, maintenance, finances, and reporting into one secure platform.

This project is intended for internal administrative use only and is **not a SaaS platform**.

---

# Main Objectives

- Simplify daily agency operations
- Improve vehicle tracking
- Manage customers efficiently
- Automate rental contracts
- Track revenues and expenses
- Monitor vehicle maintenance
- Generate reports and business insights

---

# Target User

- Agency Owner (Administrator)

There is only one administrator who has full access to the system.
